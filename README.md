# Astral — исходный код приложения

Astral — приложение для Windows, которое ставит моды в GTA V в один клик и возвращает игру обратно одним нажатием.
Официальный сайт: **https://astral-mods.online/**

Здесь опубликован исходный код приложения. Мы открыли его, чтобы каждый мог сам посмотреть, как устроен Astral и что он делает на компьютере, — и убедиться, что в нём нет ничего вредоносного.

**Текущая версия кода: Astral 1.0.6** (сборка 120).

## Как устроен репозиторий

Каждая выпущенная версия Astral попадает сюда отдельной записью (коммитом) и отметкой версии. Открыв запись, можно увидеть, что именно изменилось в коде между версиями — строка за строкой.

| Папка | Что внутри |
|---|---|
| `apps/desktop` | Основная часть приложения: установка и снятие модов, работа с файлами игры, обновления, вход |
| `apps/web` | Интерфейс: каталог, мастерская, библиотека, настройки |
| `apps/api` | Локальная служба приложения — работает только на вашем компьютере |
| `apps/beta-installer` | Установщик Astral |
| `packages` | Общие библиотеки: движок установки, форматы файлов игры, редакторы мастерской |
| `native` | Движок на Rust и вспомогательная программа на .NET для работы с архивами игры |
| `tools/rpf-helper` | Помощник для чтения и записи архивов RPF |

## Чего здесь нет

- **Серверной части и сайта.** В репозитории только то, что работает на вашем компьютере.
- **Картинок, моделей, звуков и других двоичных файлов.** Только текст исходного кода.
- **Тестов, служебных стендов и внутренних инструментов команды.**
- **Сторонних библиотек.** Они берутся из собственных репозиториев их авторов: RageLib и RageLib.GTA5 (Neodymium), CodeWalker.Core, DirectXTex (Microsoft), go-webview2. Файлы игры, её ключи и архивы в Astral не входят.
- **Паролей, ключей и любых личных данных.**

Собрать приложение только из этого репозитория нельзя: для сборки нужны ресурсы и сторонние библиотеки. Репозиторий предназначен для чтения и проверки.

## Как убедиться, что вы скачали настоящий Astral

Скачивайте Astral только с официального сайта. Контрольная сумма установщика версии 1.0.17 (SHA-256):

```
58f0b7ab42a1b525e14df551d1f060a753b4e55d84c5d2742255825256a00dc0
```

Проверить файл в Windows: откройте PowerShell и выполните `Get-FileHash путь\к\файлу.exe`.

Обновления приложения подписаны: Astral не установит обновление, подпись которого не совпала.
